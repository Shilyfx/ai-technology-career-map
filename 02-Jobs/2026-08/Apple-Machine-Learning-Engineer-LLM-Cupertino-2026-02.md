# Apple — Machine Learning Engineer, LLM

## Source Scope
Apple 官方职位页；覆盖 LLM、agents、fine-tuning、RAG 和生产平台。

## Role Summary
将 LLM 和 agent 能力集成到可评测、可运营的产品中。

## Responsibilities
- 训练/微调 LLM 与 LMM；
- 构建 agents、RAG 和工具工作流；
- 使用容器、Kubernetes、Airflow/Ray 等交付。

## Explicit Requirements
- LLM/agent 与 fine-tuning；
- Python、模型评测和生产工程；
- 能处理数据、部署和质量闭环。

## Preferred/Nice-to-have
- LangChain/LlamaIndex、Kubernetes、Docker、Ray、MLflow。
