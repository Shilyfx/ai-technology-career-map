# OpenAI — Product Manager, API Agents

## Source Scope
官方职位页；保留产品交付与技术判断信号。

## Role Summary
定义 API agent 产品、开发者体验和可靠安全的路线图。

## Responsibilities
- 把开发者需求转成 API/SDK 和 agent builder 方向；
- 设定可靠性、安全、质量和用户结果；
- 与工程、研究、设计和商业团队推进交付。

## Explicit Requirements
- 复杂技术产品管理经验；
- 能理解 API、agent、评测和生产约束；
- 路线图、优先级和跨职能沟通能力。

## Preferred/Nice-to-have
- 生成式 AI、开发者平台或安全产品经验；
- 数据驱动的产品决策。
