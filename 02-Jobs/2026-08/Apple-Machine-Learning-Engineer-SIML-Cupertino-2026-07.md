# Apple — Machine Learning Engineer, SIML

## Source Scope
Apple 官方职位页；覆盖生成模型、数据和端侧优化。

## Role Summary
训练和优化生成式模型，并将其推向高效产品环境。

## Responsibilities
- 处理 web-scale 数据和 foundation model training；
- 研究 diffusion/autoregressive 模型与 adapters；
- 做分布式训练和 on-device 优化。

## Explicit Requirements
- 深度学习、模型训练和 Python/C++；
- 生成模型或大规模数据经验；
- 能关注效率、质量和部署约束。

## Preferred/Nice-to-have
- PyTorch/JAX、分布式训练、端侧推理或量化经验。
