# Apple — Machine Learning Engineer, Eval and Insights

## Source Scope
Apple 官方职位页；覆盖 eval suites、LLM-as-judge 与安全/对齐信号。

## Role Summary
建立评测套件和洞察系统，判断模型质量、安全和变化。

## Responsibilities
- 开发自动化 eval suites 和分析；
- 研究 LLM-as-judge、RAG 和安全评测；
- 与模型团队闭环修复问题。

## Explicit Requirements
- Python、PyTorch/JAX 或 HF；
- 评测、数据分析和实验；
- 能解释指标局限。

## Preferred/Nice-to-have
- MLflow/W&B、safety/alignment、统计或产品实验经验。
