# Apple — Machine Learning Engineer, Data Curation

## Source Scope
Apple 官方职位页；覆盖数据筛选、治理和 ML 管线。

## Role Summary
让训练数据可发现、可过滤、可追溯并服务模型质量。

## Responsibilities
- 构建数据 curation、filtering 和质量管线；
- 用 SQL/Python/Java 处理大规模数据；
- 对接 PyTorch、Docker、云和训练团队。

## Explicit Requirements
- Python/Java/SQL 和数据工程；
- 数据质量、管线和 ML 系统；
- 能把数据问题量化并修复。

## Preferred/Nice-to-have
- Dagster、PyTorch、Docker、云平台或数据治理经验。
