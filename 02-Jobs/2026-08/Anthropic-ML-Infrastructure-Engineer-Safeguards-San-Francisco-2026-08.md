# Anthropic — ML Infrastructure Engineer, Safeguards

## Source Scope
官方 Greenhouse 职位页；抽取 safeguards 的数据密集型 ML 基础设施要求。

## Role Summary
构建训练、评测、打分和安全工作流的可靠基础设施。

## Responsibilities
- 设计 Python 数据与分布式工作流；
- 保障 correctness、吞吐、成本和可靠性；
- 支持模型内部、评测与安全分数管线。

## Explicit Requirements
- Python、数据密集型系统和生产工程；
- 训练/评测/打分工作流经验；
- 能维护长期运行的可靠管线。

## Preferred/Nice-to-have
- GPU、模型内部、安全评测或云基础设施经验。
