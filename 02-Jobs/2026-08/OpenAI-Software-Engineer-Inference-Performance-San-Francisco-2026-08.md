# OpenAI — Software Engineer, Inference Performance Optimization

## Source Scope
官方职位页；重点是 profiling、性能模型和 fleet 约束。

## Role Summary
用测量和运行时优化降低推理延迟、成本并提升容量。

## Responsibilities
- 建立 benchmark、profiling 和性能模型；
- 优化 kernels、accelerators 与服务 fleet；
- 在延迟、吞吐、容量和成本之间做取舍。

## Explicit Requirements
- 性能工程、系统编程和实验分析；
- GPU/accelerator 或推理运行时；
- 可把 profiling 结果转成生产改动。

## Preferred/Nice-to-have
- CUDA、编译器、kernel、调度或大规模服务经验。
