# Apple — Machine Learning Engineer, Search

## Source Scope
Apple 官方职位页；覆盖搜索、排序与大数据工程。

## Role Summary
用 NLP、检索和排序改善大规模搜索体验。

## Responsibilities
- 训练和评估检索/排序模型；
- 使用大数据管线处理搜索信号；
- 与产品和基础设施团队迭代质量。

## Explicit Requirements
- Python/C++/Java；
- NLP、搜索、ranking 与 ML；
- Hadoop/Spark/Hive 等大数据经验。

## Preferred/Nice-to-have
- Transformer、推荐系统、离线/在线实验经验。
