# OpenAI — Software Engineer, API SDK

## Source Scope
官方职位页；覆盖 SDK、API、agent 编排与开发者体验。

## Role Summary
把模型能力包装成稳定、易用、可评测的多语言 SDK 与 API。

## Responsibilities
- 维护 Python/Node/Go/Java/Ruby SDK 和 API；
- 支持 agents、orchestration、工具和错误处理；
- 通过测试、评测和文档提升开发者体验。

## Explicit Requirements
- 至少一种服务端语言和 API 设计；
- 可靠性、兼容性和开发者体验；
- 能把模型能力转成产品接口。

## Preferred/Nice-to-have
- LLM 应用、agent、评测和开源 SDK 经验。
