## 资料边界与使用规则

- 来源正文按下载时的原样保存，适合查阅配置细节；产品版本、价格、插件命令和“最佳”结论必须回到官方文档复核。
- 新的可复用知识只进入 `05-Knowledge`，并且要经过定义、适用边界、失败模式、实践和证据链接；产品名、插件名和安装步骤不自动升级为 Skill。
- 文章中的提示词、脚本和 API 配置均视为示例，不在本仓库执行；不要把任何密钥写入笔记或配置。
- `manifest.json` 保存文章数、下载 URL、发布时间和下载内容 SHA-256，便于以后增量复核。
